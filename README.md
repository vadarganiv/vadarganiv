## Featured projects

### [Servis Binjaket](https://github.com/vadarganiv/ServiceBinjacket)

A full-stack electronics repair and e-commerce application built with ASP.NET Core, Clean Architecture, EF Core/PostgreSQL, JWT authentication, automated tests, Next.js, Docker Compose, and Nginx.

### [KinoBudka](https://github.com/vadarganiv/KinoBudka)

A real-time synchronized video system with an ASP.NET Core/SignalR server and WPF/Avalonia desktop clients. The project includes authenticated control commands, validated uploads, thread-safe shared state, automated tests, and CI.

### [ExpressBot](https://github.com/vadarganiv/ExpressBot)

A .NET 8 library for bots in the eXpress enterprise messenger, with an HTTP command listener, a BotX API client, and models for notifications, chats, and users. Published on [NuGet](https://www.nuget.org/packages/ExpressBot), with setup examples and API migration notes.

### [ExpressBot.Core](https://github.com/vadarganiv/ExpressBot.Core)

A standalone .NET 8 package with JSON models, BotXApi/BotApi interfaces, and an HMAC-SHA256 signature helper for eXpress integrations. Published on [NuGet](https://www.nuget.org/packages/ExpressBot.Core) for use in custom clients and hosts.
